Q2. Fetch All the employee name & their department name they belong to & generate SQL Query ,give me the sql query 

For Q2, the requirement is to fetch all employee names along with the department names they belong to — including employees who may not be assigned to any department yet.

In this case, you should use a LEFT JOIN to ensure even employees without a department are included.

SELECT e.employee_name, d.department_name
FROM Employee e
LEFT JOIN Department d ON e.department_id = d.department_id;

Explanation:
LEFT JOIN ensures all employees are included.

If an employee doesn't belong to any department, department_name will be NULL.

Note : Employee table is left table in this join
left join =inner join+ any addition record in the left table

 Assuming Schema:
Employee(employee_id, employee_name)

Department(department_id, department_name)

Employee_Department(employee_id, department_id) → This join table holds the many-to-many mapping.

SELECT e.employee_name, d.department_name
FROM Employee e
JOIN Employee_Department ed ON e.employee_id = ed.employee_id
JOIN Department d ON ed.department_id = d.department_id;

The SQL query  uses INNER JOIN (also known simply as JOIN) 

First Join:
	JOIN Employee_Department ed ON e.employee_id = ed.employee_id

This joins the Employee table with the Employee_Department join table.

It keeps only those employees who have an entry in the Employee_Department table (i.e., who are mapped to at least one department).

Second Join:
	JOIN Department d ON ed.department_id = d.department_id;
	
This connects the Employee_Department table with the Department table.

Only departments that have a corresponding mapping in Employee_Department are included.

Type of Join Used:
Both joins are INNER JOINs, because JOIN without a keyword defaults to INNER JOIN.

INNER JOIN returns only records that match in both tables.

Find the employees who's salary is more than the average salary earned by all employees

SELECT employee_id, employee_name, salary
FROM Employee
WHERE salary > (
    SELECT AVG(salary)
    FROM Employee
);

The subquery:

	SELECT AVG(salary) FROM Employee

computes the average salary of all employees.

The outer query selects only those employees whose salary is greater than that average.
